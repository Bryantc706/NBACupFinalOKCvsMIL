# NBACupFinalOKCvsMIL
NBA Cup game analysis: Bucks vs Thunder – shot data, visualizations, and model insights

This project analyzes the Milwaukee Bucks' 97–81 win over the Oklahoma City Thunder in the 2024 NBA Cup Final using detailed shot tracking data. It explores shot efficiency by zone, clutch-time performance, player-level scoring efficiency, and defensive pressure. Visualizations include accurate shot maps, FG% by zone, and a gradient boosting model identifying key predictors of shot success. The analysis reveals how Milwaukee's superior execution—especially in high-leverage moments—led to their victory despite similar shot quality between teams.
